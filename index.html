Google Drive setup (one time)
Your ledger goes only to your own Google Drive, into a folder this app creates (“Cash Entry backups”). The app cannot see any other file in your Drive. Google's sign-in script loads only when you use this.
  1. On a computer, open console.cloud.google.com and create a project.
  2. APIs & Services → Library → enable “Google Drive API”.
  3. OAuth consent screen → External → add your own Gmail as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application. Under Authorised JavaScript origins add:
  5. Copy the Client ID and paste it below.
